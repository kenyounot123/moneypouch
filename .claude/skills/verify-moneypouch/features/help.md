# Help

## Sub-features

- Topics are a frozen registry, `Help::Topic` (`app/models/help/topic.rb`): `slug`, `title`, `section`, and `pages`, in reading order inside `Help::Topic::CATALOG`. `Help::Topic.sections` groups them by section, `Help::Topic.on(page)` lists the ones that belong on a page, `#id` is the anchor (`help-<slug>`), and `#partial` is the body, `app/views/help/topics/_<slug with underscores>.html.erb`, one per topic. Sections: Adding, What counts, Categories, Searching, Import, Bank sync, Trends, Your data. A topic with no `pages` shows only on the Help page.
- Pages are the names `HelpHelper::PAGES` maps a `controller_path` to: `overview` (`welcome`), `transactions`, `categories`, `trends`, `import` (`imports`, `imports/columns`, `imports/categories`), `review` (`simplefin/reviews`), and `settings` (`settings`, `simplefin/accesses`). `HelpHelper#help_page` reads it and falls back to `overview`. Each page has a glossary partial, `app/views/help/pages/_<page>.html.erb`, a list of term rows made with the one layout `app/views/help/_term.html.erb`, shown as `On this page`.
- The Help page, `GET /help` (`HelpController#show`), titled `Help`, with the sidebar. The header row has the `h1` and `input[aria-label="Search help"]` (full width on phones, 340px from `@2xl`). Left, from `@4xl`, `nav[aria-label=Sections]` has a hash link per section and is sticky. Right, one `section#<section id>` per section with an `h2`, then `li#help-<slug>` topics: the title in an `h3`, the body beside it from `@2xl`, stacked below. The first topic, Type a transaction, ends in the parts table: Part, You type, If you leave it out. Under 448px (`@md`) the table stacks, and the third column reads `If left out: …` (or `Required`) under the second.
- Search is client side (`filter_controller.js` on `main`). Every typed word must appear in a topic's text or its section's name, case ignored. A topic that fails is `hidden`, a section with none left hides, and the section links hide while searching. `[data-filter-target=status]` (`aria-live=polite`) reads `1 answer`, `N answers`, or `No answers for "xyz".`. Escape or `button[aria-label="Clear search"]` clears and restores everything.
- The drawer is on every page that has the sidebar, except the Help page. `_sidebar.html.erb` renders `aside#help-aside` and `dialog[aria-label=Help]`, both with the one panel `app/views/shared/_help_panel.html.erb`: the heading `Help` and `button[aria-label="Close help"]`, `On this page` with the page's glossary, `How to` with the page's topics as `details`/`summary` (a chevron that turns when open), and the footer `All topics` (`/help`) and `Keyboard shortcuts` (`shortcuts#showShortcuts`, hidden on a coarse pointer). The footer sticks to the bottom of the panel.
- From `xl` the drawer is `aside#help-aside`, 400px (`--container-help`), `order-last`, sticky, full height, scrolling inside, `bg-level-1` with a left border. It takes space, so `main` narrows. Below `xl` it is `dialog[aria-label=Help]`: a bottom sheet on phones (the transaction sheet's shape and grab handle) and a 400px panel at the right edge from `md`, over the scrim.
- Open state is `html[data-help=open|closed]`, set by `help_controller.js` and kept in the session cookie `help=open|closed`. The layout renders it from the cookie (`HelpHelper#help_state`) so the first paint has no flash, and the controller sets it again on each connect, so it stays open from page to page. The aside shows only from `xl` while it is open. Below `xl` the sheet opens and closes without touching it.
- Openers carry `data-help-target=opener`: `Help` above Settings in `_sidebar_panel` (a link to `/help` with a `?` chip while single-key shortcuts are on, hidden on a coarse pointer, below `md`, and while the sidebar is collapsed), and below `md` an icon link `header a[aria-label=Help]` left of Add. Each is a plain link, so it works without scripts, and its click (`help#open`) opens the drawer instead, except with a modifier key held. From the phone sidebar sheet it closes that sheet first. From `xl` a click toggles the aside and `aria-expanded` follows it; below `xl` it opens the sheet. On `/help` the link is the current page (`aria-current=page`, no `data-help-target`) and there is no drawer.
- Focus moves into the panel on open (the aside, or the dialog) and back to the visible opener on close. Escape closes the aside while focus is inside it. The sheet closes on Escape, a click on the scrim (`help#dismiss`), `turbo:before-cache`, a morph that touches its `open` attribute, `shortcuts:show`, and when the window becomes `xl` wide.
- `?` is `showHelp` in `shortcuts_controller.js`: it clicks the first visible `[data-help-target=opener]`, so it opens the drawer and, with the aside open, closes it. It does nothing on the Help page, in a field, or with a dialog open. `ShortcutsHelper` lists it as `Open Help ?` in the cheat sheet. Settings says `Press / to search transactions and ? to open Help. Arrows always step months.` and its `Show shortcuts` button has no `aria-keyshortcuts`. `Keyboard shortcuts` in the footer and the `See every shortcut` topic call `shortcuts#showShortcuts`, which fires `shortcuts:show` so the sheet closes first, then opens `dialog#shortcuts`.
- The toast centers on the column left of the aside while it is open from `xl`: `xl:in-[[data-help=open]:has(#help-aside)]:left-[calc(50%+(var(--container-sidebar)-var(--container-help))/2)]` in `_toast.html.erb`.
- Page layouts answer to `main`'s width, not the window's. `main` is `@container` on Overview, Settings, Trends, Categories, From your bank, Import and Help (Transactions and a category's page already were), and their variants read `@2xl:` where they read `lg:`, `@4xl:` where `xl:`, `@6xl:` where `2xl:`, so the drawer narrowing `main` gives the same layout a narrower window would. `@2xl` is 672px, `@4xl` 896px, `@6xl` 1152px of `main`'s content box. A collapsed sidebar widens `main` and moves the breakpoints with it.
- Examples in copy are `example_tag(text, kind)` (`ApplicationHelper`): mono, colored by kind as in the composer (`amount`, `money_in`, `date`, `category`).

## How to get to it (user POV)

Help, above Settings in the sidebar, or the `?` key, or the question-mark button in the top bar on a phone, or `Stuck? Help` in Get started. `All topics` in the drawer goes to `/help`.

## Driving it with mp.mjs

- Page: `mp.mjs goto /help --port N`, `mp.mjs text main --port N`. Search: `mp.mjs type 'input[aria-label="Search help"]' 'import file' --port N`, then `mp.mjs text '[data-filter-target=status]' --port N` reads `2 answers`. `mp.mjs key Escape --port N` empties it.
- Aside: `mp.mjs resize 1440 900 --port N`, `mp.mjs goto /transactions --port N`, `mp.mjs click 'aside#sidebar a[href="/help"]' --port N`, then `mp.mjs js 'document.documentElement.dataset.help + " " + document.cookie' --port N` reads `open` and `help=open`. `mp.mjs key '?' --port N` toggles it. `mp.mjs js 'document.querySelector("#help-aside").getBoundingClientRect().width' --port N` reads 400 and `document.querySelector("main").getBoundingClientRect().right` reads the aside's left edge.
- Sheet: `mp.mjs resize 375 812 --port N`, `mp.mjs click 'header a[aria-label=Help]' --port N`, then `mp.mjs js 'document.querySelector("dialog[aria-label=Help]").open' --port N` reads `true`. From the phone sidebar sheet, `mp.mjs click 'button[aria-label="Show sidebar"]' --port N` then `mp.mjs click 'dialog[aria-label=Sidebar] a[href="/help"]' --port N` closes it and opens Help. `mp.mjs js 'document.querySelector("dialog[aria-label=Help]").click()' --port N` is a scrim tap.
- Toast: with the aside open at 1280, add `tea 3` and compare the toast's center to `main`'s: `mp.mjs js 'const r = document.querySelector("[id^=toast_transaction]").getBoundingClientRect(); (r.left + r.right) / 2' --port N`.
- Overflow: `mp.mjs js 'document.documentElement.scrollWidth > document.documentElement.clientWidth' --port N` reads `false` on every page at 340, 375, 768, 1024, 1280, and 1440 wide with the cookie `help=open` and `help=closed` (`mp.mjs js 'document.cookie = "help=open; path=/"' --port N`, then `goto`).

## Gotchas

- Chrome headless will not emulate a viewport narrower than 338px here, so `mp.mjs resize 320 …` fails. Use 340, or the Browser pane.
- The aside and the sheet both render the panel, so a text search on the page finds each glossary and topic twice. Scope a selector to `aside#help-aside` or `dialog[aria-label=Help]`.
- `html[data-help=open]` can be set while no aside exists (the Help page, or below `xl`). Only `aside#help-aside` shows it.
- The scrollbar gutter stays reserved, so a right-edge sheet sits 15px short of the window's edge in a drive with classic scrollbars.
